# Smart Bus Prototype Guidelines

This repository is a simple academic undergraduate prototype. Keep the project
small, clear, and easy to explain during a college project review.

## Technology rules

- Use Java and Python only for application logic.
- HTML and CSS are allowed for browser display.
- Do not use JavaScript, Node.js, React, Spring Boot, or other heavy frameworks.
- Do not use MySQL, cloud databases, cloud services, or external APIs.
- Do not add real GPS, real bus integrations, payments, or authentication.
- SQLite may be used as a local database only.

## Scope rules

- Do not overengineer the prototype.
- New features must not be added unless explicitly requested.
- Implement only the requested project specification and preserve the simple
  separation between the Python web layer and Java business logic.
